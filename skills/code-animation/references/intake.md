# 開工前的引導問答

> 用法：**能跟使用者對話**的 agent，一題一題問（每題給選項＋建議，使用者可以直接說「照建議」）；
> **無頭派工**的 agent，從派工單裡找答案，找不到的用「建議」值，並在交件時列出「我用了哪些預設」。
> 問完把答案寫成 `brief.json`（格式見文末），**念給使用者確認後才開工**。

---

## 1. 這支片看完，觀眾要做什麼？（必答）

| 選項 | 適合 | 片子結尾會放 |
|---|---|---|
| A. 私訊／留言某個關鍵字 | 想帶來詢問、預約 | 一顆按鈕寫「私訊『關鍵字』」 |
| B. 點連結報名／購買 | 有活動頁、商品頁 | 網址或「連結在留言」 |
| C. 學會一件事 | 教學、課堂教材 | 一句重點整理 |
| D. 記住你是誰 | 品牌介紹 | 名稱＋一句定位 |

**建議**：要帶來詢問就選 A，而且**每支片用不同的關鍵字**，事後才分得出是哪支片帶來的。
**追問**：觀眾看完能帶走什麼？只報消息的片會被按讚、不會被找；要有一個「對他有用」的點。

## 2. 內容從哪裡來？（必答）

- 請使用者**貼上原稿**（文章、簡報、筆記）或給檔案路徑。
- 問：「哪些句子、數字、價格**一字都不能改**？」→ 這些逐字放進 `must_include`，驗收時會逐字比對。
- ⛔ 不要自己編數字、價格、承諾；原稿沒有的就問，不要補。

## 3. 要發在哪裡？（決定畫面比例）

| 平台 | 比例 | 尺寸（`--size`） |
|---|---|---|
| FB／IG 動態牆 | 4:5 直式 | `1080x1350` |
| Reels／Shorts／TikTok | 9:16 直式 | `1080x1920` |
| YouTube／簡報內嵌 | 16:9 橫式 | `1920x1080` |
| 不確定 | 1:1 方形 | `1080x1080` |

**建議**：4:5。動態牆上佔的面積最大，也能被裁成方形。
提醒：多數平台**預設靜音播放**——字幕是主體，配樂是加分。

## 4. 片長多久？

| 選項 | 能講多少 | 結構 |
|---|---|---|
| 15 秒 | 一個重點 | 衝突句 → 一個畫面 → 行動 |
| **30 秒（建議）** | 一個觀念＋2～4 個例子 | 起承轉合（見 SKILL.md） |
| 45～60 秒 | 一個小故事 | 角色遇到問題 → 轉折 → 改變 → 行動 |

**換算**：中文一秒約讀 5～6 個字；每句關鍵字完整出現後要**停留至少 1.5 秒**。
把原稿要上畫面的字數加總 ÷ 5 ＋ 動畫時間，超過所選片長就要刪字，不是加速。

## 5. 畫風？（給使用者看預覽圖：`references/styles/`）

| 畫風 | 範本 | 適合 | 預覽 |
|---|---|---|---|
| A. 幾何資訊 | `templates/geo.html` | 新聞整理、方法說明、方案介紹（**最穩、最精緻**） | `geo-dark.png`／`geo-light.png` |
| B. 動態文字 | `templates/motion.html` | 金句、標語、一句話一個觀念 | `motion-dark.png`／`motion-light.png` |
| C. 手繪線條 | `templates/sketch.html` | 流程、步驟、白板講解 | `sketch-dark.png`／`sketch-light.png` |
| D. 角色插畫 | `templates/peeps.html` | 有人物的情境故事 | `peeps-dark.png`／`peeps-light.png` |

**建議**：拿不定就選 A。畫風可以混用（例如 A 的版面裡放一段 B 的逐字動畫）。
⛔ 不要用程式手刻人物（火柴人在手機上像草稿）；要人物就用 D。

## 6. 配色？

| 選項 | 怎麼設 |
|---|---|
| **深色（建議，對外宣傳）** | `--param palette=dark`：深底、淺字、一個琥珀色焦點 |
| 淺色（課堂、講義感） | `--param palette=light`：米白底、黑字、一個綠色焦點 |
| 品牌色 | `--param bg=#底色 --param ink=#字色 --param acc=#焦點色`（範例：`geo-brand-example.png`） |

**焦點色只給全片最重要的一樣東西**（轉折句、價格、按鈕）。到處都用焦點色＝沒有焦點。
問使用者：有沒有不能用的顏色或字型？（寫進 `bans`）

## 7. 要不要背景音樂？

| 選項 | 做法 | 注意 |
|---|---|---|
| A. 不要 | 不加 `--music`／`--audio` | 最快；靜音播放的平台差異不大 |
| **B. 程式合成配樂（建議）** | `scripts/tone_render.py` ＋ `templates/score.js` | 音效會準確落在畫面事件上；無授權問題 |
| C. 音效點綴 | 在 score.js 用素材庫的 Kenney CC0 音效（點擊、撞擊、短配樂） | 免費可商用 |
| D. 自備音樂 | `--audio 你的音樂.mp3` | **授權使用者自己確認**（例如 AI 生成音樂的付費方案條款） |

選 B／C 再問**情緒**：輕快／沉穩／先緊張後釋放（轉折處一記重擊）。
⚠️ agent 聽不到聲音——配樂好不好聽要由使用者聽過才算數。

## 8. 交件與時限

- 輸出檔名、存放位置；要不要另外出一張封面圖（第 0 格）。
- 什麼時候要？有時效的題材（新聞）越晚發越沒用，要先講。

## brief.json 格式

```json
{
  "goal": "A",
  "cta": "私訊「試聽」",
  "takeaway": "觀眾帶走什麼",
  "source": "原稿檔案路徑或貼上的全文",
  "must_include": ["一字不改的句子", "NT$999"],
  "platform": "FB 動態牆",
  "size": "1080x1350",
  "duration": 30,
  "style": "geo",
  "palette": "dark",
  "brand": {"bg": "", "ink": "", "acc": ""},
  "music": "synth",
  "mood": "先緊張後釋放",
  "bans": ["紫色漸層", "Arial"],
  "output": "out/video-v1.mp4",
  "deadline": "",
  "defaults_used": ["duration", "palette"]
}
```
`defaults_used`：哪些欄位是用預設值、不是使用者說的——交件時要列出來。

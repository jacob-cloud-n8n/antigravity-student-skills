# AI 協作系統索引

> 這個資料夾保存跨平台的核心協作資料。平台設定只負責接線，不取代本索引與協作檔案。

## 核心入口

- 協作檔案：`profile/我的AI協作檔案.md`
- 專案區：`projects/`
- 工作協作卡：`templates/工作協作卡.md`
- 專案協作模板：`templates/專案協作模板.md`
- 收工紀錄模板：`templates/收工紀錄模板.md`

## 第二大腦

- 狀態：尚未登記
- 位置：`<相對路徑或尚未啟用>`
- 說明：已有第二大腦時只登記位置，不搬動、不複製。

## 平台接線

- Codex：`adapters/codex.md`
- Claude：`adapters/claude.md`
- Gemini：`adapters/gemini.md`

## 可攜原則

- 核心內容使用 UTF-8 Markdown 與相對路徑。
- 正式資料不只存在聊天記憶或 Skill 安裝目錄。
- 換平台後重新接線，並用一項真實工作驗證。
- Plugin、MCP、Actions、外部 API 與平台記憶需逐項重接，不視為已自動搬移。

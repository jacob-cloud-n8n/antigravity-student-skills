# 舊 AI 經驗匯入與分類

當學員用過 ChatGPT、自訂 GPT、ChatGPT Project、Gemini Gem、Claude Project、提示詞庫或其他生成式 AI 時讀取。

## 六步匯入精靈

每一步都顯示 `進度：第 N/6 步` 與下一個動作。

### 1. 辨識來源

問：用過哪些生成式 AI？最常用來做什麼？不要要求學員先懂 Instructions、Knowledge 或 connector。

### 2. 取得手上已有資料

接受任何一種：

- 貼上的 instructions／提示詞。
- 匯出的檔案或附件。
- 設定畫面截圖。
- 一段覺得很好的回答。
- 學員口述「它平常怎麼幫我」。

找不到完整資料也可以先做 instruction-only 或口述草稿，不以匯出障礙卡住課程。截圖前提醒遮住 email、電話、地址、token、私人網址與他人個資。

### 3. 安全檢查

- 憑證值不複製；改記環境變數名稱或「待連接」。
- 客戶、學生或公司資料只保留完成工作所需的最小資訊。
- 完整聊天紀錄不批次匯入，只摘取跨任務仍成立的規則、偏好與代表性案例。
- 不宣稱帳號記憶、付費能力或平台工具已搬移。

### 4. 自動分類

| 內容 | 建議位置 | 判斷方式 |
|---|---|---|
| 合作偏好、解釋方式、確認界線 | `profile/我的AI協作檔案.md` | 跨多個工作仍成立 |
| 單一工作的需求、期限、素材 | `projects/<專案>/` 或工作協作卡 | 只服務目前工作 |
| 長期參考資料、來源文件 | 第二大腦或專案 references | 需要保存與追溯 |
| 成熟、可重複的顧問／教練流程 | 候選 Skill | 在至少兩項任務仍相同 |
| Actions、Drive、Gmail、Notion、MCP、API | adapter 的「需另接」清單 | 必須逐項連接與實測 |
| 一次性的語氣或要求 | 不寫入永久檔案 | 沒有跨任務價值 |

### 5. 逐項確認

一次確認一組同類內容，顯示來源摘要、建議位置、會保留什麼、會捨棄什麼。學員可改分類；未確認不得寫入或交給下一個 Skill。

### 6. 結果與下一步

回報：已匯入、尚未寫入、需另接、刻意不搬、待確認。接著只選一個下一步：更新協作檔案、建立專案資料、轉成 Skill，或用真實工作測試。

## 何時交棒給 gpt-role-to-codex-skill

只有同時符合下列條件才建議交棒：

1. 內容是一個可重複使用的角色或流程，不只是個人偏好。
2. 學員希望它跨專案使用，或明確指定某專案使用。
3. 規則、知識、案例與平台功能已初步分離。
4. 學員已確認要產生 Skill。

若缺 Knowledge 檔，可先做 instruction-only 版本；若含 Actions／外部服務，必須列為「需另接」，直到 connector、plugin、MCP、CLI 或 API 實際可用並完成測試。
